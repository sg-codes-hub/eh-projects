# English Hub — Class 10 English 15-E Interactive

Phase 1 is the reusable, account-free front-end engine for the Class 10 First Language English (15-E) practice project.

## Current scope
- Mobile-first dashboard
- First Flight, Footprints, Grammar, Analogy, Comprehension and Composition modules
- Mark-wise practice filters (1–5 marks)
- Mock-test entry point
- MCQ rendering, instant feedback and scoring
- LocalStorage for last result (no student account/database)
- GitHub Pages-friendly static architecture

## Phase 1 note
The current repository contains **demo/sample questions only**. It is deliberately separated from the final question bank. Phase 2 will add the complete syllabus content and blueprint-mapped question data.

## Deployment
Publish the repository (or the intended project folder) with GitHub Pages. The app uses only relative static assets, so it can also be placed under a subpath such as `/english-15e/`.
