# KSEAB 15-E Previous-Paper Integration Policy

## Purpose

The Class 10 First Language English (15-E, NCERT) question bank must be informed by the widest available history of KSEAB-style assessment material, not only the latest model paper.

## Source classes

1. **Final / annual SSLC examinations** — highest-value evidence for recurring board wording, chapter selection, marks, and question construction.
2. **Supplementary / Exam-2 / Exam-3 papers** — important for identifying alternative formulations, under-tested chapters, and recurring skills.
3. **Mid-term / term examinations** — useful for early-year chapter coverage, school-level KSEAB-aligned wording, grammar progression, and additional question formulations.
4. **Official KSEAB model papers** — primary format/pattern reference for the current cycle.
5. **Official 2026–27 blueprint** — controlling specification for current-year allocation.
6. **School/teacher question papers** — secondary evidence only; useful for additional practice but never allowed to override official KSEAB requirements.

## 15-E isolation rule

Only **First Language English (NCERT), Subject Code 15-E** material is eligible for the 15-E historical evidence pool. Papers for 14-E, 31-E, or other language codes must not be mixed into the 15-E question bank.

## How historical papers will be used

Historical questions are treated as evidence, not as a list to copy blindly. For every source question we record, where available:

- academic year
- examination type (Final / Supplementary / Mid-term / Model)
- paper/version
- question number
- book
- chapter/poem
- question type
- marks
- skill tested
- grammar category, if applicable
- difficulty
- recurring-topic indicator
- answer/evaluation points
- source provenance

## Question-generation rules

- Do not duplicate a historical question merely by changing a name or one word.
- Preserve the **KSEAB-style construction** while generating fresh practice questions.
- Historical questions that recur across years receive a higher recurrence weight.
- Questions appearing in final examinations receive higher board-relevance weight than school-created material.
- Supplementary and mid-term papers expand the variation pool and help prevent overfitting to one annual paper.
- Current 2026–27 blueprint constraints always override historical frequency.
- Current textbook/syllabus scope always overrides questions from deleted or changed content.

## Planned evidence weighting

| Source | Role | Weight |
|---|---|---:|
| 2026–27 official blueprint | Current specification | 100 |
| 2026–27 official model papers | Current format | 95 |
| Recent official 15-E final papers | Board relevance | 90 |
| Recent 15-E supplementary papers | Board variation | 80 |
| Older 15-E final papers | Historical recurrence | 75 |
| 15-E mid-term papers | Skill/coverage variation | 60 |
| School/teacher papers | Supplementary practice | 35 |

These weights are **engineering priorities**, not official KSEAB statistics.

## Coverage objective

The final bank should contain enough independent questions to support:

- chapter-wise practice
- grammar drills
- skill-wise practice
- easy/medium/hard practice
- previous-paper-inspired revision
- mixed revision
- full 47-question mock papers
- multiple mock-paper generations without obvious repetition

## Current evidence note

The project already contains the 15E 2025–26 Model Question Paper-1 and the current 2026–27 15E blueprint reference. Publicly discoverable sources also confirm the existence of 2024 15-E final papers, 2023 15-E supplementary papers, and 2025–26 Karnataka SSLC First Language English mid-term material. These sources will be used to locate and analyse additional papers, while any paper whose full contents are not actually retrieved will remain a source-inventory item rather than being represented as analysed content.
