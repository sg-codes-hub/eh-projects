# Class 10 English 15-E Question Bank

This directory contains the interactive content data for English Hub's Class 10 First Language English (15-E) practice application.

## Structure
- `questions.json` — core starter questions
- `banks/manifest.json` — list of modular question-bank files loaded by the app
- `banks/first-flight-prose-batch-01.json` — First Flight prose expansion
- `banks/first-flight-poetry-complete.json` — First Flight poetry expansion
- `banks/footprints-complete.json` — Footprints Without Feet expansion
- `banks/grammar-composition-complete.json` — grammar, analogy, comprehension and composition expansion

## Question schema
Each question should contain an `id`, category/book/chapter metadata, `marks`, `type`, `question`, and either `options` + `answer` for objective items or `answer` for written items. Explanations/model-answer guidance should be included whenever appropriate.

The bank is designed to be expanded in reviewed batches. Blueprint labels are planning metadata and should not be presented as official chapter guarantees unless verified against the latest KSEAB publication.
