# 15-E Historical Paper Mining

## Purpose
Build the English Hub Class 10 First Language English (15-E) question bank from historical KSEAB 15-E evidence while keeping the 2026-27 blueprint as the controlling specification.

## Evidence hierarchy
1. 2026-27 official 15-E blueprint
2. 2026-27 official/model material
3. 15-E final/annual papers
4. 15-E supplementary / Exam-2 / Exam-3 papers
5. 15-E preparatory/model papers
6. School mid-term/term papers supplied to the project

## Mining dimensions
For every historical question, record:
- year/period
- paper type
- paper/version identifier
- original question number
- section/question slot
- book
- chapter/poem
- question form
- marks
- skill/competency
- grammar subtype where applicable
- exact-repeat status
- concept-repeat status
- provenance

## Recurrence analysis
Do not treat an exact repeated question and a recurring concept as the same signal.

Track separately:
- exact repeats
- near repeats / reworded repeats
- recurring chapter concepts
- recurring grammar constructions
- recurring question formats
- recurring literary skills

## Bank-generation policy
Historical questions may be retained as labelled PYQs. New questions should be generated from recurring KSEAB patterns without unnecessary verbatim duplication. Historical frequency must never override the 2026-27 blueprint.

## 15-E isolation rule
Only material explicitly identified as First Language English (NCERT), code 15-E, may enter the historical 15-E corpus. Do not import 14-E or 31-E questions merely because the wording or textbook looks similar.

## Current verified web evidence
Public indexing confirms a 2024 KSEAB 15-E final paper with 47 questions and code 15-E, and public listings identify 15-E Exam-2, Exam-3 and supplementary papers for 2024 plus 15-E supplementary papers for 2023. These sources are discovery aids; individual questions must be verified against the actual paper before being entered as PYQs.
